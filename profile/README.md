# The UBIT Hub

An independent student-led developer and academic community for students of UBIT, University of Karachi.

## Our Purpose

The UBIT Hub connects students across batches and sections to:

- Build open-source projects that solve real student problems
- Collaborate on software development
- Share technical knowledge and academic resources
- Help students grow their GitHub, development, and career skills
- Create opportunities for juniors and seniors to learn from each other

## Open Source

We aim to build useful open-source tools for the UBIT community.

Our first major project will be the **UBIT Result Portal**, which is currently being prepared for collaborative development.

## Community

The UBIT Hub currently connects **900+ students** across different batches and technical interests.
